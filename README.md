INVESTIQ 
InvestIQ is an intelligent stock screening, recommendation, and learning platform designed for beginner investors. It uses a completely local rule-based engine and machine learning (scikit-learn) under the hood to explain stock analysis dynamically.

Setup Guide
1) Clone or Download the Repository
2) Set up a Virtual Environment (Recommended):
      python -m venv venv
      source venv/bin/activate  # On Windows: venv\Scripts\activate
3) Install Dependencies: pip install -r requirements.txt
4) Run the Application :
       streamlit run app.py
